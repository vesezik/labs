Каталог корисних та популярних інтернет-ресурсів:

Google
Google — один із найпопулярніших в Україні та світі пошукових серверів.
Поштова служба Gmail
Gmail — безкоштовна електронна пошта від компанії Google із надійним захистом.
GitHub
GitHub — найбільший веб-сервіс для хостингу IT-проєктів та спільної розробки коду.
MDN Web Docs
MDN — найвідоміший довідник для веб-розробників, де зібрана вся документація про HTML, CSS та JavaScript.
Національний університет «Полтавська політехніка»
НУПП — офіційний сайт університету імені Юрія Кондратюка.
Портал дистанційного навчання НУПП
Модуль НУПП — платформа для віддаленого навчання, перегляду лекцій та здачі лабораторних робіт.
YouTube
YouTube — найбільша платформа для пошуку, перегляду та публікації відеоматеріалів.
